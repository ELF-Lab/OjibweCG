# Disambiguation grammar

This is the master document for all cases the disambiguation grammar handles. This can be used for both tracking existing functionality and future development. All Ojibwe examples are from the [gold disambiguation set](../evaluation/eval_data/gold/disambig_gold_492.txt). 

Most recent update: May 25, 2026 



## 1. Blanket constraints

### 1.1 Adverbs

#### 1.1.1 Locative adverbs

**Ambiguity handled:** Locative constructions composed of a noun and a prenoun (e.g. *naawi-ziibi* 'in the middle of the river') are given two parses: a lexicalized `ADVLoc` parse and a decomposed prenoun + noun (e.g. `PNLex/` + `NI`)  parse. 

**Generalization:** Select the locative adverb reading across the board. We run this here so these constructions are not spuriously treated as nominal arguments for verb disambiguation. Selecting the lexicalized `ADVLoc` reading is consistent with selecting other lexicalized readings (see 5.1).

**CG rule:** `SELECT:select_adv_loc TARGET (ADVLoc) ;` "Select the locative adverb (`ADVLoc`) reading ATB."

**Example:** *naawi-ziibi* 'in the middle of the river'

 In: 
 ```
 "<naawi-ziibi>"
	"naawi-ziibi" ADVLoc
	"ziibi" PNLex/naawi NI Sg
```

Out: 
```
"<naawi-ziibi>"
	"naawi-ziibi" ADVLoc
```

**Limitations:** There are no other ambiguities involving a locative adverb that I am aware of. In case there are, this rule has to be changed, as it would spuriously select the `ADVLoc` reading in unrelated cases.

### 1.2 Idiosyncratic verb ambiguities

#### 1.2.1 Impersonal verbs

**Problem handled:** Impersonal VII verbs, including weather verbs (e.g. *gimiwan* 'it rains') and temporal verbs (e.g. *waaban* 'it is tomorrow'), are ambiguous with respect to the subject in the conjunct form. For example, *waabang* (conjunct form of *waaban*) has both singular inanimate (`0SgSubj`) and plural inanimate (`0PlSubj`) subject readings.

**Generalization:** Impersonal verbs are semantically unspecified for a subject, analogous to dummy subject constructions in English (e.g. 'it is raining'), so we remove the spurious plural inanimate subject ATB.

**CG rule:** `REMOVE:rem_pl_for_impersonal_verbs PL_INAN_SUBJECT IF (0 IMPERSONAL_VERB) ;` "Remove plural subject reading if current token is an impersonal verb."

**Example:** *waabang* `it is tomorrow` (conjunct)

 In: 
 ```
 "<waabang>"
	"waaban" VII Cnj Pos Neu 0SgSubj
	"waaban" VII Cnj Pos Neu 0PlSubj
```

Out: 
```
 "<waabang>"
	"waaban" VII Cnj Pos Neu 0SgSubj
```

**Limitations:** The set `IMPERSONAL_VERB` is manually defined, and surely does not contain all impersonal verbs yet. Best to expand systematically. 

#### 1.2.2 Intransitive plural verbs

**Problem handled:** Certain intransitive VAI and VII stems are only compatible with plural subjects, which is captured by the special VAIPL and VIIPL classes. For example, *dashiwag* 'there are so many of them' is a VAIPL stem which takes a plural subject. In certain cases, a VAIPL/VIIPL reading is generated alongside an otherwise equivalent VAI/VII reading, which does not represent a true ambiguity, rather a less specific tag being generated.

**Generalization:** Remove the VAI/VII reading if a more specified VAIPL/VIIPL reading is given.

**CG rule:** `REMOVE:VAIPL_over_VAI (VAI) IF (0 (VAIPL)) ;` "Remove `VAI` reading if contains more specified `VAIPL` reading" (analogous rule exists for `VIIPL`)

**Example:** *endashiwaad* `there are so many of them' (changed conjunct)

 In: 
 ```
 "<endashiwaad>"
	"dashiwag" ChCnj VAIPL Cnj Pos Neu 3PlProxSubj
	"dashi" ChCnj VAI Cnj Pos Neu 3PlProxSubj
```

Out: 
```
 "<endashiwaad>"
	"dashiwag" ChCnj VAIPL Cnj Pos Neu 3PlProxSubj
```

**Limitations:** No obvious limitations here.

### 1.3 Dialect-specific blanket constraints

#### 1.3.1 RCs: *gaa-* over `Pcp`

**Problem handled:** Dialects of Ojibwe differ in relativization strategies (see Sullivan (2016)), with the two main strategies being a *gaa-* relativizing prefix and participle (`Pcp`) morphology, which is realized as initial change (IC). Roughly, northern varieties use the *gaa-* relativizer while southern varieties use the participle form. Morphologically, the *gaa-* prefix overlaps with the past tense participle form, where the past tense prefix *gii-* combines with IC to form *gaa-*.

**Generalization:** If we know that the dialect of the current speaker exclusively uses the *gaa-* relativizer, we can remove the `Pcp` reading across the board. 

**CG rule:** `REMOVE:no_pcp_dialect (Pcp) IF (0 (VAR:has_gaa)) ;` "Remove any participle reading if the dialect exclusively uses *gaa-* for RCs."

**Example:** *gaa-inaajimotawi* 'what he tells/told me'

 In: 
 ```
 "<gaa-inaajimotawid>"
	"inaajimotaw" ChCnj PVTense/gii VTA Cnj Pos Neu 3SgProxSubj 1SgObj
	"inaajimotaw" PVSub/gaa VTA Cnj Pos Neu 3SgProxSubj 1SgObj
	"inaajimotaw" PVTense/gii VTA Pcp Pos Neu 3SgProxSubj 1SgObj 3SgProxHead
```

Out: 
```
"<gaa-inaajimotawid>"
	"inaajimotaw" ChCnj PVTense/gii VTA Cnj Pos Neu 3SgProxSubj 1SgObj
	"inaajimotaw" PVSub/gaa VTA Cnj Pos Neu 3SgProxSubj 1SgObj
```

**Limitations:** The *gaa-* vs. participle relativization strategies are not in direct competition, and there are dialects which can employ both strategies (Sullivan 2016:280), which means this rule is not effective in all cases. Furthermore, it is inherently difficult to identify the dialect of a speaker without prior knowledge, meaning this rule will only run when the specific dialect is inputted. A potential avenue is a system which can use linguistic cues to automatically identify the given dialect.


#### 1.3.2 RCs: `Pcp` over *gaa-*

**Problem handled:** Same as 1.3.1.

**Generalization:** If we know that the dialect of the current speaker exclusively uses participle morphology, we can remove the *gaa-* relativizer reading across the board. 

**CG rule:** `REMOVE:no_gaa_dialect (PVSub/gaa) IF (0 (VAR:has_Pcp)) ;` "Remove any *gaa-* reading if the dialect exclusively uses the participle form for RCs."

**Example:**  *gaa-inaajimotawi* 'what he tells/told me'

 In: 
 ```
 "<gaa-inaajimotawid>"
	"inaajimotaw" ChCnj PVTense/gii VTA Cnj Pos Neu 3SgProxSubj 1SgObj
	"inaajimotaw" PVSub/gaa VTA Cnj Pos Neu 3SgProxSubj 1SgObj
	"inaajimotaw" PVTense/gii VTA Pcp Pos Neu 3SgProxSubj 1SgObj 3SgProxHead
```

Out: 
```
"<gaa-inaajimotawid>"
	"inaajimotaw" ChCnj PVTense/gii VTA Cnj Pos Neu 3SgProxSubj 1SgObj
	"inaajimotaw" PVTense/gii VTA Pcp Pos Neu 3SgProxSubj 1SgObj 3SgProxHead
```

**Limitations:** See limitations for 1.3.1.


## 2. Verbal disambiguation

### 2.1 Argument ambiguities

#### 2.1.1 Subject

**Problem handled:** A verb can be ambiguous to which subject it encodes. Cases include obviative subjects, which are ambiguous for number, and overlapping verb forms. For example, certain verb stems may have overlapping VII and VAI forms, which leads to an animacy ambiguity of the subject (see example).

**Generalization:** If there is an agreeing nominal element within the immediate clause, choose the reading that agrees with the animacy/number of the overt nominal. Given the relatively free word order of Ojibwe, the agreeing nominal can be either pre- or post-verbal. The immediate clause is delimited by a clausal boundary, which is defined as all verbs with the exception of adjunct (adjectival-like) verbs (e.g. impersonal verbs) and verbs in the nominal domain (e.g. relative clauses). This clausal boundary is used for all relevant verbal rules. 

**CG rule:** `SELECT:inanimate_subj_rule_1 SG_INAN_SUBJECT IF ((-1* NI_NID + (Sg) BARRIER CB) OR (1* NI_NID + (Sg) BARRIER CB));` "Select the singular inanimate subject reading if there is a surrounding inanimate singular noun, stopping at a clausal barrier." (analagous rules for singular/plural proximate and plural inanimate subjects)

**Example:** *Gii-mizhakiise iwe waasigan.* 'The lightning hit the ground.'

 In: 
 ```
 "<gii-mizhakiise>"
	"mizhakiise" PVTense/gii VII Ind Pos Neu 0SgSubj
	"mizhakiise" PVTense/gii VAI Ind Pos Neu 3SgProxSubj
"<iwe>"
	"iwe" PRONDem NI Sg
"<waasigan>"
	"waasigan" NI Sg
"<.>"
	"PUNCT" 
```

Out: 
```
"<gii-mizhakiise>"
	"mizhakiise" PVTense/gii VII Ind Pos Neu 0SgSubj
"<iwe>"
	"iwe" PRONDem NI Sg
"<waasigan>"
	"waasigan" NI Sg
"<.>"
	"PUNCT" 
```

**Limitations:** The clausal boundary which delimits the search for an agreeing nominal may not be fully articulated, and may need to be amended to handle edge cases.
