# References & Credits  

Reference to the knowledge and people who made this project possible can be found here!

## References  
A list of core (not exhaustive) references for the creation of the project.

1. Valentine, J. R. (2001). *Nishnaabemwin Reference Grammar*.  
   - Core linguistic reference for Ojibwe morphosyntax.  

2. Bick, E., & Didriksen, T. (2015). *CG-3 — beyond classical constraint grammar*.  
   - Overview of CG-3 architecture and extensions beyond traditional CG.  

3. Karlsson, F. (1990). *Constraint grammar as a framework for parsing running text*.  
   - Foundational paper introducing Constraint Grammar.  

4. Schmirler, K., Arppe, A., Trosterud, T., & Antonsen, L. (2018). *Building a constraint grammar parser for Plains Cree verbs and arguments*.  
   - Key reference for applying CG to Algonquian languages.  

5. Sullivan, M. (2016). *Relativization in Ojibwe* (PhD thesis).  
   - Detailed typological and syntactic analysis relevant to dialectal variation and clause structure in Ojibwe.  

6. Didriksen, T., & Bick, E. (2025). *VISL CG-3: Constraint Grammar Compiler and Tools*.  
   - Documentation and implementation reference for CG-3 tooling.  

7. Nichols, J. D. (2012). *The Ojibwe People’s Dictionary*.  
   - Lexical resource for Ojibwe forms and sentence examples.  

8. Universal Dependencies Consortium. (2024). *CoNLL-U Format (Universal Dependencies)*.  
   - Specification for dependency annotation format used in UD-style treebanks.
