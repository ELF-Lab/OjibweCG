# Work in Progress

## Current focus

**March 2026**
- RCs: We are currently working on improving coverage for RC parsing, both for disambiguation and dependency parsing.
- Discontinuous DPs: We are working on mapping discontinuous DPs in the dependency grammar
- Dialect-sensitive parsing: We are working on implement a dialect-sensitive parsing module, allowing for more fine-grained disambiguation
  
## Future areas

- Mapping clausal dependencies: We do not yet handle clause-level dependencies (e.g. attaching embedded clauses to matrix clauses).
- Building a treebank: We aim to create a fully verified Ojibwe treebank, for which improved coverage of the grammars is necessary, though the parsing pipeline is already in place. 
- Application to treebank studies: We plan to apply the work to other areas of interest such as argument realization, etc.
